# 法律咨询 · 案情评估工具（可部署到 GitHub，微信可分享）

一个**纯静态、零后端**的客户自助咨询页：客户填写案情经过、时间线、证据情况与诉求，页面按常见法律规则生成
结构化分析（法律关系 → 救济路径 → 时效提示 → 证据缺口 → 风险 → 行动清单）。

**客户资料不上传任何服务器**，只存在客户自己手机的浏览器里。

## 二、部署到 GitHub Pages

### 方式 A：网页操作（不用命令行）

1. 登录 GitHub → 右上角 **+** → **New repository**
   - Repository name：`legal-consult`（随意）
   - 可见性：**Public**（Private 仓库用 Pages 需付费账号）
   - 勾选 **Add a README file** → **Create repository**
2. 进入仓库 → **Add file** → **Upload files** → 把 `index.html` 拖进去 → **Commit changes**
3. **Settings** → 左侧 **Pages** → Source 选 **Deploy from a branch**，
   Branch 选 **main**、目录选 **/ (root)** → **Save**
4. 等 1–2 分钟，页面会显示网址：
   `https://<你的用户名>.github.io/legal-consult/`　← 这就是分享链接

### 方式 B：命令行（改完可反复推送）

```bash
cd 法律咨询工具
git init
git add index.html README.md
git commit -m "feat: 法律咨询案情评估工具"
git branch -M main
git remote add origin https://github.com/<你的用户名>/legal-consult.git
git push -u origin main
```

然后在 GitHub 网页上按方式 A 的第 3 步开启 Pages。

### 自定义域名（可选）

仓库 **Settings → Pages → Custom domain** 填你的域名，并在域名服务商处添加 CNAME 记录指向
`<你的用户名>.github.io`。国内域名需完成 **ICP 备案**才稳定可用。

## 三、微信分享注意事项

- **直接发链接即可**：把 `https://<用户名>.github.io/legal-consult/` 发给客户，微信内置浏览器可正常打开、填写、生成报告。
- **自定义分享卡片**（标题、缩略图）：需要**已认证公众号 + JS-SDK 签名**，当前版本未接入；默认分享卡片会取页面 `<title>` 与描述。
- **国内访问稳定性**：GitHub Pages 在国内时快时慢，甚至偶发打不开。若要给客户长期用，建议二选一：
  | 方案 | 说明 |
  |---|---|
  | **Gitee Pages** | 国内快，需实名认证；免费版有时需手动更新 |
  | **腾讯云 COS / 阿里云 OSS 静态托管** | 稳定、可绑自有域名，需实名与备案（域名） |
  | **Cloudflare Pages / Vercel** | 免费、部署简单，国内访问中等 |
- **合规提示**：面向公众提供服务的网站，使用**国内主机/域名**时通常需 ICP 备案；用境外托管（GitHub Pages）虽免备案，但被微信拦截或限速的风险更高。

## 五、想改内容？定位很简单

`index.html` 里三处可直接编辑：

| 位置 | 作用 |
|---|---|
| `var TYPES = [...]` | 案件类型下拉选项（增删类型） |
| `var EVIDENCE = [...]` | 证据勾选项（通用清单） |
| `var KB = { ... }` | **规则引擎主体**：每个类型对应 `cause`（案由）、`relation`（法律关系）、`paths`（救济路径）、`limits`（期限时效）、`evidence`（必备证据，第三项 `true` 表示必备）、`risks`（风险）、`actions`（行动清单） |

增删案件类型时，只需在 `TYPES` 加一项、在 `KB` 里加同名 key 的配置即可。

  需同步修改隐私告知（此时数据会离开设备）。
- **导出 PDF 报告**：当前支持「打印 / 存为 PDF」与「导出文本」，如需固定版式可引入打印样式表。
- **证据截图上传**：目前仅做本地勾选；如需附证据图片，可在本地预览（仍不上传）。
